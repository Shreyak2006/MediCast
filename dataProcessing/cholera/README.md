- processed/cholera_state_month.csv

Processing:
- Filtered records for Cholera.
- Aggregated records by state and month.
- Preserved the monthly reported outbreak burden as the prediction target.
- No zero-filling of missing state-month observations.

Modifications and derived files prepared for the MediCast project.
