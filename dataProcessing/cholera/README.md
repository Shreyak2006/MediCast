## Data Processing

- Filtered records for Cholera.

- Aggregated records by state and month.

- Preserved monthly reported outbreak burden as the prediction target.

- Did not fill missing state-month observations with zero.

## Modifications

The original dataset was filtered and processed to create Cholera-specific datasets for the MediCast project. The processed files are derived from the original EpiClim dataset.
